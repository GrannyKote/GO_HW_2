# GO_HW_2

Два сервиса в одном репозитории: **Gateway** (HTTP-шлюз) и **Ledger** (учёт транзакций в памяти).

## Требования

- Go 1.21+ (или любая актуальная версия с поддержкой modules)

## Gateway

HTTP-сервер на порту `8080`.

```powershell
cd gateway
go run .
```

Проверка:

```powershell
curl.exe http://localhost:8080/ping
```

Ожидается ответ `pong` и статус `200 OK`.

## Ledger

Сервис хранит транзакции в памяти, добавляет их через `AddTransaction` и выводит список при старте.

```powershell
cd ledger
go run .
```

В консоли должны появиться сообщение о старте, предупреждение об ошибке для транзакции с нулевой суммой и список из трёх добавленных транзакций.
